# Hey, Mr. Gibson

Dennis the Menace's "HEY, MR. WILSON!" with the name swapped to Gibson, cleaned up and
levelled. A personal parody clip, shared with family.

**Listen / download:** https://reddragon1g.github.io/hey-mr-gibson/

|---|---|
| `audio/hey-mr-gibson.mp3` / `.wav` | just the yell, background removed |
| `audio/hey-mr-gibson-with-background.mp3` / `.wav` | keeps the original room underneath |

48 kHz mono, −11.4 LUFS.

## How it was made

"Wilson" and "Gibson" differ over only 0.30 seconds — both are `_ɪ_ + s + ən`, and only
the consonants around the vowel change. The long held "-sooon!" that carries the whole
sing-song is identical in both words, so it is the original recording. Only the 0.30 s
"Wil" was replaced, with a syllable rendered by IndexTTS-2 conditioned on the source
clip for both voice and performance. **87% of what you hear is the original audio.**
