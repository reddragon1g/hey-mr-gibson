# Hey, Mr. Gibson

Dennis the Menace's "HEY, MR. WILSON!" with the name swapped to Gibson. A personal
parody clip, shared with family.

**Listen / download:** https://reddragon1g.github.io/hey-mr-gibson/

## How it was made

"Wilson" and "Gibson" differ over only 0.30 seconds - both are `_I_ + s + ən`, and only
the consonants around the vowel change. The long held "-sooon!" that carries the whole
sing-song is identical in both words, so it is the original recording. Only the 0.30 s
"Wil" was replaced, with a syllable rendered by IndexTTS-2 conditioned on the source
clip for both voice and performance. **87% of what you hear is the original audio.**

The ringtone music is synthesised from scratch (no sample clearance to worry about) and
written in E-flat at A4 = 429.2 Hz rather than 440, because the yell's sustained
"-sooon" measures 607 Hz - which at that tuning is exactly E-flat 5. The held note
therefore lands on the root of the chord under it instead of fighting it.
